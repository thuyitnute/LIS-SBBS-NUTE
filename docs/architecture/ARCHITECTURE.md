# LIS Architecture

## Learning Intelligence Infrastructure

Version: 0.2.0

---

# 1. Overview

LIS (Learning Intelligence Infrastructure) is an AI-Native
learning infrastructure designed to transform traditional
Learning Management Systems into intelligent knowledge ecosystems.

LIS follows the Smart Black Box System (SBBS) architecture.

Core principle:

Human + AI + Knowledge = Intelligent Learning Infrastructure


---

# 2. System Architecture


```
LIS Platform

        |
        |
        +----------------+
        |
   Smart Black Boxes

        |
        +-- Core Box
        |
        +-- Knowledge Box
        |
        +-- AI Agent Box
        |
        +-- Trust Box

```


---

# 3. Smart Box Architecture


## 3.1 Core Box

Location:

```
app/core
```

Responsibility:

- System initialization
- Configuration
- Runtime management


---

## 3.2 Knowledge Box

Location:

```
app/knowledge
```

Responsibility:

- Knowledge Atom
- Knowledge Graph
- Living Knowledge


---

## 3.3 AI Agent Box

Location:

```
app/agents
```

Responsibility:

- AI Agent management
- Reasoning workflow
- Human-AI collaboration


---

## 3.4 Trust Box

Location:

```
app/trust
```

Responsibility:

- Identity
- Permission
- Governance


---

# 4. Development Philosophy

LIS is developed through incremental Smart Box evolution.

Each Smart Box contains:

- Capability
- Interface
- Data Model
- Intelligence Layer
